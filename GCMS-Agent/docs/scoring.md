# 谱图证据、评分与评估契约

[English](scoring.en.md) | **简体中文**

本项目输出的 `confidence_score` 是 **0–100 的规则支持峰强覆盖分**，不是分子正确概率，也不是预测谱与实验谱的余弦相似度。只有独立开发集上的校准实验才能赋予后续概率字段以统计含义。

## 输入强度

当前输入使用 `input_ids`（整数名义 m/z）与 `intensity`（未分箱的原始线性强度），编码为 `raw_linear`。保留输入值 `raw_intensity`，模型读谱直接使用 `intensity = raw_intensity = I`，计分使用 `w_i = I_i / sum(I)`。读谱峰强和计分权重不可混淆；不固定假设输入最大值为999，也不对小整数强度猜测分箱编码。

输入必须为等长非空数组；m/z 为唯一正整数；强度为有限非负数且至少一个正值。不接受布尔值、NaN、无穷、负值或重复 m/z。零信号保留在推理源数据中，但不作为观测峰进入枚举、评分或模型谱表。所有正强度峰均保留，不做弱峰阈值过滤、对数变换或取整。

`lower` / `upper` 是兼容字段，均等于输入原始峰强。没有输入测量误差模型；不能把点值解释为实验无误差。旧 `position_ids` 分箱数据明确拒绝，须从原始强度源重新准备到新目录，不能把桶号改名当作线性强度。

输入格式及公开人工示例见[数据说明](../data/README.md)。任何一批数据的最大强度或归一化习惯都不能替代接口约定，也不能据此断言输入是仪器绝对计数。

## 可以计分的证据

[规则引擎](../src/gcms_agent/fragmentation/rule_engine.py)使用固定模板枚举路径。母体必须通过严格化学检查，且为中性、连通、闭壳层结构。分子离子和后续离子允许奇电子状态，使用独立的元素/氢/电荷账本，不将断键后自动补氢的 RDKit 中性碎片当离子。

当前 [rules.json](../resources/ei_rules/rules.json) 启用 16 个规则 ID（`ei-conservative-1.3`），下表将部分同类通道合并说明。完整逐项条件、来源及局部推广限制见 [CONDITIONS.md](../resources/ei_rules/CONDITIONS.md)。

| 规则 | 实现边界 |
| --- | --- |
| 分子离子 | 单电荷分子自由基阳离子假设 |
| 烷基 sigma 裂解 | 全碳母体、指定饱和碳环境、单次断键能分开组分 |
| 羰基/杂原子相关 alpha 裂解 | 满足代码中键环境与元素条件的碳骨架裂解 |
| 苄位、烯丙位裂解 | 指定邻接芳香或烯烃稳定化环境；烯丙位的断键保留端碳必须在母体中为饱和碳（相连键全部为单键），排除自身参与双键或三键的位置 |
| 卤素自由基丢失 | 饱和碳与单个卤素之间的适用键 |
| M-H、M-H2 | **仅限乙烷结构的已列通道**，不推广至任意 C-H |
| 醇脱水 | 羟基、适用 alpha/beta 碳及可用氢同时满足 |
| McLafferty 型路径 | 羰基与明确 alpha-beta-gamma 链、gamma 氢及守恒产物 |
| 酰鎓离子丢失 CO | 羰基 alpha 裂解后的特定二步路径 |
| 烯基腈脱 HCN | 末端腈基连接非芳香 C=C，有 beta-H 且该双键不在环内；记录 beta-H 转移与双键变三键，仅单步模板 |
| 芳基腈脱 CN 自由基 | 芳香碳通过单键桥连接末端腈基；指定 C/N 作为中性自由基离去，不转移氢 |
| TMS 甲基自由基丢失 | 明确的三甲基硅局部环境，按实现限定断裂 Si–C 键并检查产物；不推广至任意含硅结构 |
| TMS 阳离子裂解 | 明确的 TMS 锚定环境，按实现断裂锚定键并检查产物；N/S/饱和 C 局部推广仍是模板假说 |

当前 `max_steps=2` 并不表示支持所有两步串联反应；除已实现的二步规则外，不递归组合任意模板。任意环双断裂、任意 HCN 丢失链、未列出的重排均不计分。含硅特异通道仅限已实现的 TMS 模板；非 TMS 硅、任意氢转移及未列出的重排不因质量相符而计分。

模板检查包括实际断键存在、保留原子与中性产物的元素/氢守恒、总电荷守恒、奇偶电子一致性和结构适用条件。`verified=true` 表示通过这些程序检查，**不代表实验确认了碎裂机理或离子生成强度**。

整数谱峰采用名义同位素质量匹配，不采用“精确质量简单四舍五入”替代。报告中的精确离子 m/z 扣除电子质量；母体中性精确质量独立计算。M+1/M+2 仅作同位素假说注释，不计作独立断键支持，也不用于确认同位素比例。

当前路径上限为 10000，统计发生在路径去重及观测峰匹配之前。再生成路径将超过上限时，证据接口返回 `complete=false`；不使用截断后的部分覆盖给候选正常排名。上限不是支持峰个数限制。

## 分数与兼容字段

令 `a_ij=1` 表示候选 j 至少存在一条合格路径匹配观测峰 i，否则为零。

```
S_j = sum(w_i * a_ij)
confidence_score_j = 100 * S_j
S_lower = S_upper = S_j
```

每个峰最多计一次，多条机制解释同一峰不会增加分数。原始输入顺序、重复候选数、扩散模型分数及 LLM 语言确信度不进入上述计算。分子离子峰已属于覆盖计数，不额外重复加权。未解释峰保持在分母中。

上下界兼容字段均等于点分，不计算分箱区间、分箱敏感性、区间竞争者或稳健区间分差。排名报告保留最高分并列集合、相同支持峰集合、点分差与未解释强度；测量不确定性未建模，结构身份及规则覆盖仍存在不确定性。

输出逐峰 `weight`、`supported`、`contribution`，以及 `supported_peaks` 和 `unassigned_peaks`，可独立重算总分。合法但完全没有支持峰的结构得零分；化学非法结构或证据计算未完成的结构分数为 `null`，二者不得混淆。

## 编辑验收

首次把非法母体修成满足约束的合法结构时可以保存，允许零分，不要求命中最高强度桶。后续合法结构探索不再要求分数增益或新增支持峰。化学验证、重原子组成、去重和证据完整性仍是硬约束。

当前探索图与历史最佳图分离：同分或降分提案可成为下一轮起点；最终输出历史最高点分结构，同分保留较早结构。历史图连同验证、证据和图版本保存，恢复时继续原探索游标。获准探索不等于科学证据改善。

## 排名与边界

按 canonical isomeric SMILES 合并最终结构，相同结构的分数必须一致，来源记录全部保留。按 S 降序排列；分数在 `1e-12` 内视为并列。最高分并列时按下述来源计数规则选择Top1，其余并列仍按 canonical SMILES 固定展示顺序。零分候选可保留，全部零分时不给出确定 Top1；全部失败时不编造结构。

覆盖评分更容易奖励具有多种可达碎片的结构，并不能预测竞争反应与离子丰度；精确结构识别性能需要独立评估。最高分不能单独证明结构正确。

## 最高分并列的来源计数规则

当至少两个不同最终结构并列最高证据分时，在这个集合内按原始来源候选个数降序选择 Top1；个数仍相同则按 canonical SMILES 字典序选择。每条原始候选槽位一票，重复输入及其共享计算结果均计票。独立计算候选数另行记录，不代替来源票数。低分结构不能靠票数超过高分结构。

规则版本为 `top_score_source_count_v1`。`top1` 和 `unique_ranking` 的展示次序体现该规则；`rank`、`tied` 与 `top1_candidates` 仍保留证据分排名及最高分并列集合。来源票数不改变证据分，不代表独立实验支持或身份概率。Acc@1 使用实际选择的 `top1`，MRR 使用展示列表位置；未完成运行的严格端到端口径不变。历史冻结结果保留原排序，需要重排时生成独立派生目录。


## 证据状态与实现依据

[计分函数](../src/gcms_agent/scoring/support.py)输出逐峰贡献；[排序器](../src/gcms_agent/scoring/ranking.py)合并相同最终结构并保存来源槽位。`identity_confirmed` 保持 false，`measurement_uncertainty_modeled` 表示当前未建模测量误差。

`molecular_ion_only` 表示仅有分子离子支持，缺少对同质量异构体的碎片区分证据。`majority_intensity_unassigned` 描述超过一半峰强未被规则解释，不是新增的编辑拒绝阈值。报告还列出最强未解释峰。路径数量、协议完成和高覆盖均不能替代独立身份鉴定。

## 独立评估约定

推理端只接收无标签输入。标签在单独评估阶段按 `sample_id` 关联；不把答案、事后解释或据答案调出的提示写回技能、模型输入或共享探索摘要。为调试而查看过答案的样本属于开发用途，不能继续当作未接触的留出集。

比较时固定输入与来源顺序、规则、配置、技能和代码版本，并分别报告：原始候选顺序、确定性规则重排序、Agent 编辑与重排序。三个流程的候选来源与评估定义应保持可比；不能把基线结果称为模型编辑效果。

[评估器](../src/gcms_agent/evaluation/runner.py)读取已保存结果与独立标签。通用 `evaluate` 命令不会自动建立或验证预测冻结清单；需要严格实验冻结时，应在加载标签前另行保存预测文件哈希及版本记录。只调用 CLI 不能代替实验隔离流程。

| 指标或口径 | 含义 |
|---|---|
| `Acc@1` | 按记录的 `top1` 计算，空 Top1 不因展示数组首项碰巧命中而获得命中 |
| `Acc@10`、`MRR` | 对 Agent/规则结果使用唯一结构展示顺序；MRR 是首次命中位置倒数，未出现为零 |
| 原始候选顺序指标 | 使用原始槽位顺序，其 @k 与去重后的唯一结构排名口径不同 |
| 输出合法率 | 非空输出中通过严格化学验证的比例；无输出时返回 null |
| 修复率与改坏数量 | 分别检查初始非法槽位最终是否合法、原本正确槽位是否被改错；合法不等于身份正确 |
| `processed`、`complete_only` | 分别针对已保存结果和其中完整结果，不代表全部请求样本 |
| `requested_set` | 包含未处理样本，缺失结果按未命中计；已保存的临时排名可参与 |
| `strict_end_to_end_requested_set` | 未完成或未处理样本按未命中计，避免只统计容易完成的样本 |

具体指标实现见 [metrics.py](../src/gcms_agent/evaluation/metrics.py) 与 [baselines.py](../src/gcms_agent/evaluation/baselines.py)。候选源槽位数与唯一结构数都应保留；少于十个唯一结构时不为计算 Acc@10 补造候选。并列按实际记录顺序评估，不使用乐观的并列命中口径。

完整实验报告还应包含处理率、失败类型、费用与未知用量、耗时口径及数据划分。小规模开发样本、人工例子和离线模拟测试不证明真实模型准确率或全量成本。后续若拟合评分参数或概率校准，应使用独立开发数据，并避免同一分子的谱图跨开发和最终测试分组。

无需私有数据的基线与评估命令见[公开人工示例](../data/examples/README.md)。真实数据集的原始输入、标签和具体案例结果不随这些技术说明发布。
