# 从节点与边识别分子结构

用于支链、芳香/稠环或官能团定位。先核对输入图，下面的局部模式用于识别结构，不直接证明某个实验峰或碎裂机制。示意中的 R/R′ 表示已有原子组成的剩余结构，不是允许新增的节点或当前支持的 Markush 语法。

## 连接、支链和环

- 数原子看唯一节点及元素，不看 ID 最大编号、文本出现次数或分子名称。节点在多条边中出现仍是同一个原子。普通氢数来自标签；显式 H 节点另计。
- 邻接表必须由所有边建立。`A --- B` 与 `B --- A` 是同一连接；节点声明的先后位置不表示主链顺序。局部邻居数与键级之和不同，例如一个双键邻居只算一个邻居。
- 判断支链要找分叉连接及其完整去向。`[CH]` 本身不能说明是支链中心、烯烃碳还是芳香碳。解释时给出目标 ID 及邻居，不只说“第二个碳”。
- 环是沿真实边回到起点的闭合路径，中间原子不重复。不能把 SMILES 环号或节点编号当环；删掉一条环键后图可能仍连通，不能立即称为两个碎片。
- 两个环共享一条边及两个端点是稠合的典型情形；只共享一个原子是螺环。桥环应核对桥头之间不同路径，不能看到画面交叉就宣称成键。
- 一个环基中的独立环数可由 `E - V + C` 校对（E 为边数、V 为节点数、C 为连通分量数），但这不是所有简单闭合路径的数量，复杂环系也不应假定唯一环分解。实际环的说明仍需给出沿边闭合的原子序列。
- 六元芳环的邻/间/对位置按环上最短边数 1/2/3 判断，不按 ID 数字之差；稠环、杂环不能机械套此命名。

## 从官能团连接识别，避免只看标签

| 局部结构事实 | 可以识别的局部类型与边界 |
|---|---|
| C === O | 羰基；继续看羰基碳的其他邻居及 H，不能立刻断言是酮 |
| 羰基碳带 1 H，另连 C | 常见醛；甲醛羰基碳带 2 H，是单独边界 |
| 羰基碳单键连两个 C，H=0 | 常见酮 |
| 羰基碳另单键连带 H 的 O | 羧酸片段；这一个 OH 不应另当独立醇羟基 |
| 羰基碳另单键连 O，O 再单键连 C | 常见酯片段；若 O 另一端也是羰基碳，先检查酸酐，不能忽略两端的羰基环境 |
| 羰基碳另单键连 N | 酰胺片段，不把该 N 只按普通胺理解；氨基甲酸酯等可含重叠局部片段 |
| 带 H 的 O 单键连饱和 C / 芳香 C | 普通醇 / 酚的候选局部环境；先排除羧酸、过氧化物等其他邻接 |
| O 无 H、两条单键连 C | 醚式连接；先检查是否属于酯、酸酐或其他羰基衍生物 |
| C -.- N | 腈式连接；通常 C 与 N 标签均无附着 H，仍核对其余邻接/电荷 |
| N(+) 连一个双键 O、一个单键 O(-)，另单键连 C | 常见硝基表示；净电荷为 0，不应把两原子的电荷分别清零 |

为每个相关片段列出明确原子 ID，如“羰基为 C_a=O_b，C_a 另连 O_c，O_c 连 C_d”。不同片段可共享原子，不能把各官能团的原子数相加当作总原子数。异常价态图先描述现有连接与冲突，不把拟修复后的官能团当成输入事实。

## 编辑前后的局部记账

在已有节点之间改一条键后，核对两端及相关邻居：键级总和、氢数、电荷、自由基、芳香性、是否位于环和是否有立体限制。普通中性闭壳层非芳香 C/N/O 的常见价态可分别用 4/3/2 自检，但不是适用于所有元素与电荷态的统一公式。未知氢先标未知，合理赋值仍须工具确认。

建立一个连接与单独删键并不必然需要相同方向的氢变化；要根据整个操作组的最终连接计算，而不是逐步自动补氢。重原子数固定不表示总氢数、分子式或分子质量固定。两个候选即使总分子式一致，也需重新计算对应谱图证据。

修复分支读工具反馈：未知氢定位到具体节点；过价检查全部相邻键及 H；芳香错误检查整条环路径、杂原子氢和芳香标记；连通错误检查操作后所有分量。不能以换节点名、删元数据或复制 SMILES 的方式绕过问题。

## 接到质谱碎片解释

母体的结构优化与碎片形成是不同的图变化。先定位实际母体键，再查看工具给出的碎片保留原子、中性产物、氢变化及电荷/自由基。断键后不能将两个片段各自补成中性饱和分子，再把所得质量当离子峰。

环内一次断键可能只打开环而未分离原子集合；苄位/烯丙位必须沿边找到芳环/烯键及相邻位置；不能把“存在某官能团”直接当作某条规则已适用。工具返回的规则和守恒检查决定是否计分，模型可以说明未实现的假说，但不自行标记 verified。
