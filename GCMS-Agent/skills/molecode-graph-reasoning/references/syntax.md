# gcms-molecode-1 语法与兼容边界

适用范围是本项目的候选小分子；不能将上游完整 MoleCode、Mermaid 的其他语法直接带入。输入格式可解析、分子化学合法、获得谱图支持是三个独立条件。

## 原子和键

原子通常写为 `prefix_Element_Number[Label]`。ID 是整个节点的稳定名字，跨轮编辑保持不变；同一元素的编号不要求连续，也不对应 SMILES 重新 canonical 化后的顺序。元素以节点标签及 `graph.atoms[].element` 为准，不能用字符串包含 C 来把 Cl 算作碳。

标签的顺序是 `[同位素质量数(可选) + 元素 + H及数量(可选) + 电荷(可选)]`，未知氢额外用 `;H=?`：

| 标签 | 精确含义 |
|---|---|
| `[C]`、`[CH]`、`[CH2]` | 一个碳，氢数依次为 0、1、2；不是根据剩余价态自动推断 |
| `[NH2(+)]`、`[O(2-)]` | 显式氢数与形式电荷；这种语法能解析，不代表给定连接下化学合法 |
| `[13CH3]`、`[2H]` | 一个碳-13 附带三个氢；一个独立的氘原子节点 |
| `[C;H=?]`、`[N(+);H=?]` | 氢数未知，`graph` 中为 `null`；保持未知直到提案明确修复 |

没有 H 字样且没有 `;H=?` 的标签表示氢数为 0。常规 H 存于原子属性中，不需要额外添加 H 节点。若输入已有显式氢/同位素氢节点，要按真实边计数，不能重复算进附着氢。未知氢存在时不能声称已经精确确定总氢数和分子质量。

键只支持 `---`（1）、`===`（2）、`-.-`（3）、`<-->`（芳香，内部编码 1.5）。键连接两个真实 ID；同一原子对不因倒写顺序产生另一条键。`-->` 配位键、`:`、`--`、`===|cis|` 等不属于当前格式。

`graph TB` 与 `graph LR` 只控制排版。`subgraph` 只分组，既不隐含成键，也不代表一定是独立分子；是否连通由边决定。普通 `%%` 注释和名称不是结构证据。生产输出每行单独声明一个原子或一条边，不使用 Mermaid 的链式、复合边等简写。

## 芳香性与元数据

合法 SMILES 通常先转换为 Kekulé 单双键；不能只因 `aromatic=false` 就认定单双键环不具有化学芳香性。RDKit 会在最终验证时重新感知。非法原始图或无法 Kekulé 化的输入可保留 `<-->`，不能见到该符号就当作格式错误，也不能把声明当作芳香性证明。

普通中性苯环中，只有两个环邻居的碳通常是 `[CH]`，连外部取代基或稠合后有三个重原子邻居的碳通常是 `[C]`。不要把此经验套用到所有杂环、电荷或自由基状态。1.5 是芳香键的表示代码，不是给所有芳香原子机械补氢的公式。

本项目有保留语义的元数据：

```text
%%@codec gcms-molecode-1
%%@atom Mol_C_2 {"aromatic":false,"radicals":0,"chiral_tag":1,"atom_map":0}
%%@bond Mol_C_2 Mol_C_3 {"stereo":3,"stereo_atoms":["Mol_C_1","Mol_C_4"]}
```

上述是字段示意，不是一张完整分子图。`aromatic` 表示当前芳香标记；`radicals` 是自由基电子数；`chiral_tag` 是依赖邻接顺序的 RDKit 标签；`atom_map` 是原子映射号而非节点 ID。键的 `stereo_atoms` 是两端的有序参考原子。零值也不应在真实图编辑时擅自清除；通过 MCP 操作让工具保留未修改的属性。

## 立体化学的实际边界

| 情况 | 当前处理 |
|---|---|
| 从含 `@` / `@@` 的 SMILES 转入 | 在 `%%@atom` / JSON 中保留 `chiral_tag` 和邻接顺序；整数 1/2 不能直接解释成 R/S |
| 上游 ID 后缀 `_R` / `_S` | 当前解析器明确拒绝；不能自行去后缀来绕过，否则可能丢失构型 |
| `===\|E\|` / `===\|Z\|` | 必须同时有一致的 `%%@bond`，包含 `stereo` 和两个参考原子；裸标签或矛盾信息会拒绝 |
| 当前 MCP 编辑 | 不提供 `chiral_tag`、`stereo`、`stereo_atoms` 的修改参数；不要提交这些字段 |
| 已指定手性中心的邻接集合或氢数改变 | 当前拒绝，需要超出本版本的立体重指定能力；不要删除原立体信息 |
| 同一邻接键移除再添加 | 工具维护相对顺序，不能用这种操作暗中翻转构型 |
| 原图没有指定立体化学 | 保持未指定；名义质量峰不能据此补定 R/S 或 E/Z |

编辑普通键时仍需检查是否涉及已指定双键构型；不能把可能丢失立体信息的变更当作普通格式修复。是否被工具支持与能否由谱图确定分别说明。

## 不属于本任务的上游功能

聚合物重复计数 `×n`、`TL/TR` 端基、Markush `{R1}` / `{Boc}` 缩写、dummy `*`、配位化学、多个反应物合并和重原子增删不属于当前候选编辑能力。最终母体必须单连通、总电荷为零、闭壳层并通过严格验证；硝基这类内部电荷分离并不违反“总电荷为零”。碎片离子另外记电荷/自由基，不套用母体闭壳层限制。

需要操作例子时用 `read_reference` 读取 `molecode-graph-reasoning/examples/transaction.md` 或 `molecode-graph-reasoning/examples/repair.md`。
