# 验收与停止

多项编辑作为原子事务：副本应用全部操作 → 图语法 → 重原子组成 → 中性/连通/化学有效性 → 往返 → 碎片证据 → 验收。中间状态可以暂时不满足价态，最终状态不可以。
已有合格图时，化学合法、未重复且证据计算完整的提案可以继续探索，不要求分数增加或新增支持峰。同分和降分结构不会覆盖历史最佳结果；没有合格图时首次化学合法修复不设强峰门槛。
正式提交的提案分别验证，宿主从合格项中择优应用到当前探索图；历史最佳结果另行保留，不由模型自行宣布 accepted。

候选默认最多三轮，实际轮数上限由运行配置决定。批审中，一次分析调用每候选最多三个替代提案，同一会话可在调用额度内多次分析，最终每候选至多提交三个试验引用；不能把试验总量与正式提交上限混为一谈。
批审宿主接受新的合格探索结构时，停滞计数清零，包括同分或降分探索；这不表示历史最佳分数提高。未接受新结构且满足完整探索条件时才累计停滞：已有不同结构的合法、证据完整试验，四项检查齐全，并且没有待提交的合格历史最佳分数改善试验。未满足完整探索条件的本轮计数清零；网络/格式错误、零试验或仅非法试验不作为化学停滞证据。默认累计达到两轮时可由停止规则判为停滞，合法 keep 也可能先满足下述提前完成条件。达到规则覆盖上限可以停止，但不能称为已鉴定。
批审合法 keep 满足以下条件时由程序自动提前完成：四项图、价态、谱图和替代假设检查齐全，已有不同结构的化学合法、谱图枚举完整试验或可核验的历史重复探索，且没有提升历史最佳分数的未提交试验。工具和宿主核验后才标记 `review_complete`，不依赖模型额外请求；单独声明保留仍然无效。探索不足时记录反馈，最大轮数仍会终止搜索。具体调用见 `constrained-structure-edit/references/batch-review.md`。
超时、预算、格式修复耗尽或服务错误是资源/执行终止。停止时返回最佳已验证版本；从未得到合法结构则 `final_smiles=null`，原始非法字符串仅保留在来源记录。
不能将预算停止写成收敛，也不能将“化学合法”写成“真实结构正确”。
