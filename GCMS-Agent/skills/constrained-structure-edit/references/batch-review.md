# 同一谱图的候选批审

每个候选具有独立 `candidate_id`、稳定原子 ID 和 `graph_version`。本批共享谱图，不共享原子身份或最终判断。提交必须覆盖本批全部候选；分组只影响调度，不改变十条原始来源的保留。一次 SDK 会话是一个提交窗口，宿主后续轮次继续搜索；不要求本次会话试遍所有可能编辑。

- `analyze_proposals` 的 `proposals` 数组一次接收多个 `{candidate_id,base_version,operations}`，同时验证、计算谱图证据和分数。同一次分析调用中，每候选最多三个替代提案；同一会话可多次调用，调用次数受会话额度限制。单个提案的操作项数不限；修改氢和连接仍是一个事务。
- 工具返回 `trial_id`、合法性、点分及兼容上下界字段、支持峰及证据引用。当前有分数时 `score_lower = score = score_upper`，不是测量误差或统计置信区间；无有效分数时可为 `null`。结果为空/失败时不能假装已验证。需要完整碎片路径时查询证据，不重抄整个历史。
- `submit_reviews` 的 `reviews` 数组必须覆盖本批全部候选，每个候选条目的 `proposals` 至多包含三个试验引用；每个引用只含 `trial_id`、`reason`、`peak_refs`、`operation_explanations` 四个字段，不复制分析阶段的 `base_version` 或 `operations`。逐项解释数组长度等于该试验的 `operation_count`，不是改变的原子数；不能只用试验 ID 代替解释。`stop_review` 是兼容旧调用的提示，直接省略；是否审查完成由宿主决定。
- `trial_id` 绑定本谱图、候选、图版本及规则。不能跨候选借用，即使 canonical SMILES 相同。宿主检查实际图和编辑，最终决定验收。
- 先充分审阅每个待探索候选及谱图，比较保留与替代假设，再选择有区分价值的方案，核对最终图的价态与配套氢修改后合并分析。每次分析调用中每候选最多三个替代是上限，不是任务指标；不预设只试一个，多个合理假设可在同一分析调用中比较。根据反馈决定修正、继续探索或提交，同时遵守会话实际剩余调用额度；资源不足时如实记录未完成问题。
- `trial_memory` 中历史 ID 是审计摘要，不能直接用于新会话的提交；重新分析对应操作后才在当前会话注册，计算可命中缓存。当前版本合格而未提交的试验一直保留为待处理项，不被最近历史窗口截断。
- `keep` 时提案为空。完成 `graph_read`、`valence_checked`、`spectrum_checked`、`alternatives_checked`，已有不同结构的化学合法、谱图枚举完整试验或可核验的历史重复探索，且没有提升历史最佳分数的未提交试验时，工具和宿主自动结束审阅；不依赖模型另行设置 `stop_review=true`。零试验或仅非法试验不证明审阅完成，也不计作有依据的停滞；未满足条件时仍受最大轮数限制。
- 若试验因价态失败，按工具错误重新核对受影响原子的键级和、显式氢和电荷后重试；该失败不能排除整个替代结构假设。未解释峰用于提出可验证的键级/连接替代，不用当前规则缺少路径证明候选无可改进。
- 若有合格试验，不得仅凭未验证的峰强猜测将其忽略；提交候选解释后由宿主验收。非法候选没有通过最终化学验证时不能报告成功修复。
- 初始 `session_budget` 给出宿主额度。工具的 `session_control` 报告剩余探索调用数、已观察响应数和 `preferred_action`；这些不是 SDK 精确剩余轮次。`preferred_action=submit_reviews` 时优先完成提交；`submit_only=true` 时仅可提交/修正提交格式。预算耗尽也必须覆盖全部候选：有可提交 trial 的用 edit，其余用暂时 keep 并说明审查未完，未做的检查不要标真。宿主仍会检查探索是否充分，不把这种 keep 视作完成。
- 每项操作用“原子/键及属性变化；工具峰路径或配套价态修复”的短句，`summary` 给一句证据摘要，不命名整分子或重抄图、谱表、patch。没有路径的峰不能写成已解释碎片；存在同位素峰不代表比值已拟合，未预测强度的路径不称“主导”。
- `submit_reviews` 成功后工具给出 `preferred_action=end_session`，立即结束；不要再查询、分析或写额外报告。排名与 Top1 碎片表由宿主输出。

各工具的精确字段以本会话 schema 为准。测试答案不得写入技能或经验；同 case 的确定性结果缓存只减少重复计算，不能充当新谱图证据。
