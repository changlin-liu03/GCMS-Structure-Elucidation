# TMS 直接断裂的适用边界

仅支持中性四配位 Si、四条重原子单键、至少三个末端 CH3；第四连接原子为普通价态的非芳香、仅单键 C/N/O/S。Si-H、Si-halogen、Si-Si、非TMS、羰基/不饱和/芳香连接原子不在此版范围。

- `tms_methyl_radical_loss`：真实断开 Si–CH3，Si侧阳离子与甲基自由基配平。
- `tms_cation_cleavage`：断 Si–X 后，Si侧必须恰为 Si 与三个甲基，产生三甲基硅基阳离子和互补自由基。
- 不转移氢，不递归扩展；同位素质量由映射原子计算，不能硬编码73或15。
- 两类路径附产物图、映射和参考。产物表示验证不等于机制确证或丰度预测。
- 原始谱可能包含59/75/147，但当前没有对应的正式硅重排模板，不能自报支持。
- 不同结构可能有完全相同的73/102/117支持集合。覆盖率相同不能说明身份相同。

来源：https://doi.org/10.1021/acs.analchem.1c02838 。O-TMS示例支持直接通道；N/S/饱和C适用范围是明确标注的局部结构推广，不能说文献确认了每个取代物的断键。
