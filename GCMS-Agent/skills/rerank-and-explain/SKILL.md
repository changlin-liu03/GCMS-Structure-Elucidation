# 排序与可解释性

所有数值分数由工具计算：`100 * sum(w_i * a_ij)`，其中 a 是固定规则支持指示，w 是原始线性强度除以全谱强度之和。报告称为规则支持的证据分。未输入测量误差时上下界兼容字段等于点分，不输出分箱误差区间。
不自行给出置信数，不将其解释为结构正确概率；同一峰只计一次。分数排名由规则支持分决定，输入顺序和 Diffusion 旧分数不作为排序依据；重复来源不会增加证据分。最高分并列时，宿主按最终结构对应的原始来源候选数量降序选择展示 Top1，数量仍相同再按 canonical SMILES 字典序选择。每个原始候选槽位计一次，包括共享计算的重复来源；来源数量不是独立谱图证据，不改变分数、并列名次或最高分集合。
十条候选来源必须保留，最终相同结构共享分数。并列结构报告并列；全部零分时不做确定性结构选择。预算导致候选尚未全部审阅时排名标记为未完成。
最终宿主结果的 `top1_candidates` 和 `ranking_diagnostics` 描述排序歧义；候选审查阶段无需请求这些尚未生成的字段。Top1 是稳定展示代表，不代表已唯一鉴定。并列时列出整个最高分结构集合；规范SMILES字典序没有谱学意义。当前无分箱区间，不能将同分解释为量化误差；身份与规则覆盖的不确定性仍需明确。
根据已有证据路径区分分子离子峰、碎片峰与断键峰（最终报告汇总为 `evidence_profile`）；这些集合可能重叠，不能相加重复计分。仅有分子离子支持时明确“无法据此区分同质量异构体”；相同支持峰集合不能被描述为区分结构的证据。若证据分低于50，表述为“按输入原始峰强计算，大部分观测强度未解释”，不能据此断定结构错误。
Top1 解释优先覆盖强峰、分子离子假说和主要未解释峰。逐项引用工具给出的断键 ID、离子式、理论与观测 m/z、重排/中性丢失和局限。
规则支持路径仍是碎片形成假说，不是实验确认。没有规则支持的解释与未解释峰明确分开；不补编碎片来使报告看似完整。
编辑验收核验图合法性、组成约束与证据完整性，允许同分或降分探索，不保证证据增益；模型的命名、共轭判断、同位素比例和主导通道措辞没有因此自动通过验证。缺少相应工具结果时只陈述图操作和被验证的峰路径，把额外机制判断标作待验证假说。
