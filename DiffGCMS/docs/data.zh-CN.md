# DiffGCMS 数据格式

[English](data.md) | 简体中文

运行入口见 [README](../README.zh-CN.md)。仓库读取已经预处理的 JSONL，每行对应一个谱图及其分子图，不直接接收原始仪器文件。

## 字段约定

| 字段 | 类型 | 要求与用途 |
|---|---|---|
| `input_ids` | 整数数组 | 必需；m/z token，默认范围 0–500，最多 300 个峰 |
| `position_ids` | 整数数组 | 必需；强度 log-bin，默认范围 0–29，与峰数组等长 |
| `node_types` | 字符串数组 | 必需；按节点顺序给出重原子元素，默认最多 50 个 |
| `edge_index` | 两个整数数组 | 建议显式提供；COO 格式 `[源节点列表, 目标节点列表]`，下标从 0 开始 |
| `edge_types` | 整数数组 | 与边数一致；1 单键、2 双键、3 三键、4 芳香键 |
| `smiles` | 字符串 | 用于真实分子重建与评估，建议提供 |
| `inchi` | 字符串 | 可选；评估优先尝试使用，失败后尝试 SMILES |
| `formula` | 字符串 | 可选；开启 `validate_formula` 时检查所支持元素的重原子总数 |
| `atom_hydrogens` | 整数数组 | 可选；与节点数一致，缺省为零；生成分子时不使用真实氢数 |

默认元素及索引固定为：

```text
0:C  1:N  2:O  3:F  4:Cl  5:S  6:P  7:Si  8:Br  9:I
```

谱图和节点数组应非空。不要把 collate 阶段的 padding 写入原始记录：数据加载器根据数组长度生成有效峰 mask，token 0 本身不会被自动当作 padding。

## 构图示例

以下是用于说明字段的人工样本，谱峰数值不代表乙醇的实测谱，不适用于性能评估：

```json
{"input_ids":[31,45,46],"position_ids":[29,15,10],"node_types":["C","C","O"],"edge_index":[[0,1],[1,2]],"edge_types":[1,1],"smiles":"CCO","formula":"C2H6O","atom_hydrogens":[3,2,1]}
```

该图含 0–1 和 1–2 两条单键。每条无向键只记录一次，构图器自动添加反向边。无键由稠密化函数补齐，无需在 `edge_index` 中列出。

输入统一采用上述 COO 格式。每条无向键仅记录一次，不包含重复边、双向重复边、自环或越界下标。

## 谱图预处理

输入数据需预先转换为整数 m/z token 和强度 log-bin。强度归一化、log-bin 阈值、峰排序和筛选规则应与所用编码器及训练数据保持一致。

复现实验时应保存预处理配置。超出峰数或节点数上限的样本会被过滤，不会被截断。

`validate_formula` 只检查受支持元素的重原子总数，不验证每种元素计数、氢数、形式电荷或 SMILES 与图的一致性。

## 划分与统计

准备独立的 `train.jsonl`、`valid.jsonl` 和 `test.jsonl`。划分与去重在数据准备阶段完成；请记录划分依据、比例及各集合的样本数。默认目录名为 `split_90_5_5`。

| 文件 | 内容 |
|---|---|
| `atom_types.txt` | 原子频率，顺序与原子表一致 |
| `edge_types.txt` | 无键、单键、双键、三键、芳香键频率 |
| `n_counts.txt` | 以节点数为索引的分布 |
| `valencies.txt` | 价数直方图，当前以整数索引入桶 |

```bash
python -m scripts.compute_stats --jsonl ../dataset/split_90_5_5/train.jsonl --stats-dir ../dataset/split_90_5_5/stats
```

脚本使用默认原子表和 300 峰上限，节点上限可通过 `--max-nodes` 调整。请使用过滤后仍有有效样本的训练集生成统计量；修改数据、原子表或过滤条件后，应重新生成并检查全部统计文件。

复现流程使用独立脚本从训练集预先生成全部四个统计文件。请记录统计文件来源，并检查数组长度、有限性和归一化结果。

## 缓存与路径

数据集使用字节偏移随机读取，在 JSONL 旁写入 `<文件名>.offsets.npz`，因此当前要求数据目录可写。缓存按文件时间、大小和部分过滤参数判断是否复用。

自定义位置时同时指定 `dataset.datadir` 和 `dataset.stats_dir`。相对路径以仓库父目录为基准，绝对路径按原位置使用。仅测试模式目前仍需要三个划分文件，详见 [实验复现说明](reproducibility.zh-CN.md)。
